## 🚀 Featured Project

### 🏥 PolicyLens — Self-Correcting Healthcare RAG

An evidence-grounded healthcare policy intelligence system built over **OPTN transplant policies**.

PolicyLens combines **semantic + lexical retrieval, Reciprocal Rank Fusion, evidence-sufficiency assessment, conditional query rewriting, retrieval recovery, citation validation, and LLM-based reflection**.

**Evaluation**
- 530 section-aware OPTN policy chunks
- 50-question section-labeled benchmark
- **93.0% Recall@5**
- **95.3% Hit Rate@5**
- **0.806 MRR**
- **100% abstention accuracy across 7 unsupported benchmark cases**

The system can detect insufficient evidence, rewrite the retrieval query, retry retrieval, and safely abstain rather than generate an unsupported policy answer.
